# MindMates Datenschutz

Öffentliche Datenschutzseite für MindMates Sudoku und MindMates Kreuzworträtsel, ausgeliefert über GitHub Pages:
https://haenrie.github.io/mindmates-privacy/

- Seite: [index.html](index.html), eine statische Datei ohne Build-Schritt.
- Löschweg ohne App (für Google Play, Feld „Link zum Löschen des Kontos“): https://haenrie.github.io/mindmates-privacy/#loeschen
- Bei Änderungen das Datum „Stand“ oben auf der Seite anpassen.
- Die Seite beschreibt das Schema der beiden App-Repos (`supabase/migrations`). Ändert sich dort, welche Daten gespeichert werden oder wie lange, wird diese Seite im selben Zug angepasst.
